Sơ Đồ Kiến Trúc Hệ Thống (End-to-End Pipeline)

Cách thức dữ liệu chuyển đổi từ Kịch bản văn bản sang Video phim mã hóa hoàn chỉnh.

1

LLM Parser

Trích xuất Cảnh, Visual Prompt, Prompt góc quay & Lời thoại từ kịch bản gốc.

Model: GPT-4o / Qwen2.5
2

Character Gen

Tạo hình ảnh nhân vật nhất quán qua LoRA / ControlNet cho từng phân cảnh.

Model: Flux.1 / SDXL
3

Image-to-Video

Chuyển hình ảnh tĩnh thành video chuyển động sống động 24 FPS.

Model: Wan2.1 / Kling
4

TTS & Lipsync

Tạo giọng đọc truyền cảm và đồng bộ chuyển động khẩu hình nhân vật.

Model: F5-TTS / LivePortrait
5

FFmpeg Render

Ghép các Scene, chèn nhạc nền, hiệu ứng chuyển cảnh & xuất file MP4.

Engine: MoviePy / FFmpeg
pipeline_runner.py (Backend Orchestrator) Python / Async FastApi 
# Mẫu mã nguồn Backend chạy Pipeline bất đồng bộ
async def generate_movie_from_script(script_text: str):
    scenes = await llm_parser.extract_scenes(script_text)
    video_clips = []
    
    for scene in scenes:
        character_img = await flux_gen.generate_frame(scene.visual_prompt)
        video_clip = await wan21_engine.img_2_video(character_img, scene.motion)
        audio_voice = await tts_engine.synthesize(scene.dialogue)
        synced_clip = await lipsync.apply(video_clip, audio_voice)
        video_clips.append(synced_clip)
        
    final_mp4 = ffmpeg_stitch(video_clips, bgm="cinematic_soundtrack.mp3")
    return final_mp4
